# AI 原理图评审系统 (MVP)

本项目基于 Docker + uv 构建，旨在通过 AI 技术实现原理图评审的自动化。

## 快速开始

### 前提条件
- Git
- Docker Desktop
- IDE (推荐 Trae / VS Code)

### 启动开发环境
1. **初始化环境**
   ```powershell
   .\scripts\bootstrap.ps1
   ```
2. **启动服务**
   ```powershell
   .\scripts\dev.ps1
   ```
