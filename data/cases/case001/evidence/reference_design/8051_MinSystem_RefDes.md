## 2. 电源设计

标准 8051 最小系统电源部分应包含：

1. **VCC 去耦电容**：每个 VCC 引脚就近配置 0.1μF 陶瓷电容（必选）
2. **低频储能电容**：电源入口处配置 10μF 电解电容（推荐）
3. **电源指示 LED**：可选

**常见错误**：省略去耦电容，导致 MCU 在开关瞬间电源轨波动。

## 3. 时钟设计

- 晶振频率：11.0592MHz（标准波特率应用）
- 负载电容：22pF
- 布局：晶振靠近 MCU，走线对称，下方铺地
- 电气网络：XTAL1 与 XTAL2 经晶振及负载电容构成振荡回路（本 IR 中合并为单一网络 `XTAL_OSC`）

## 4. 复位设计

- RC 复位：R1=10kΩ，C3=10μF → τ=100ms
- 上电复位拓扑：C3 接于 VCC 与 RST 之间，上电瞬间在 RST 产生高电平复位脉冲
- 手动复位：常开按键 SW1 并联在 RST 与 VCC 之间，按下拉高 RST
- 复位保持时间：≥ 2 个机器周期
