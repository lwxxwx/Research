# Case002 电路设计说明

> 案例元信息与设计背景，供规则引擎/RAG/评审参考

## 1. 案例来源

8051 最小系统 + AMS1117-5.0 LDO 电源系统，从 12V 降压到 5V。

## 2. 电路组成

| 元件 | 型号/参数 | 作用 |
|---|---|---|
| U1 | STC89C55RC（DIP-40） | 8051 微控制器 |
| **U2** | **AMS1117-5.0（SOT-223）** | 5V LDO 稳压器 |
| Y1 | 11.0592MHz 晶振 | 系统时钟源 |
| C1/C2 | 22pF | 晶振负载电容 |
| C3 | 10μF | 复位延时电容 |
| C4 | 0.1μF | VCC 去耦电容 |
| C5 | 10μF | LDO 输出滤波电容 |
| R1 | 10kΩ | 复位下拉电阻 |
| R2 | 10kΩ | 复位上拉电阻 |
| SW1 | 常开按键 | 手动复位 |

**元件数**：11
**网络数**：6（VIN_12V / VCC / GND / XTAL_OSC / RST / EA_GND）

## 3. 已知设计缺陷

### 缺陷 E1：LDO 功耗超降额（high）

- **现象**：U2 实际功耗 3.5W，超过阈值 0.8W
- **计算**：P = (Vin - Vout) × Iout = (12 - 5) × 0.5 = 3.5W
- **阈值**：额定 1W × 降额系数 0.8 × 温度系数 1.0 = 0.8W
- **后果**：LDO 过热，可能触发过温保护、损坏或影响可靠性
- **规则命中**：POWER_003
- **对应 Ground Truth**：`DEF-CASE002-1`

## 4. 已验证的优良实践

1. **LDO 输入输出滤波电容配置**：C5=10μF 输出 + C4=0.1μF 高频
2. **复位 RC 参数合理**：τ=100ms
3. **晶振负载电容对称**：22pF / 22pF
4. **复位拓扑正确**：R2 上拉

## 5. 观察项（非缺陷）

- IO 引脚悬空（由 IO_001 汇总提示）
