# Case003 电路设计说明

> 案例元信息与设计背景，供规则引擎/RAG/评审参考

## 1. 案例来源

基于 case001（8051 最小系统）派生，做两处修改：
1. **引入缺陷**：C1 值从 22pF 改为 10pF（晶振负载电容不匹配）
2. **修正基线缺陷**：新增 C4（去耦电容）+ R2（复位上拉），让 case003 只测 CLOCK_001

## 2. 电路组成

| 元件 | 型号/参数 | 作用 |
|---|---|---|
| U1 | STC89C55RC（DIP-40） | 8051 微控制器 |
| Y1 | 11.0592MHz 晶振 | 系统时钟源 |
| **C1** | **10pF（误用）** | 晶振负载电容（应为 22pF） |
| C2 | 22pF | 晶振负载电容 |
| C3 | 10μF | 复位延时电容 |
| **C4** | **0.1μF** | VCC 去耦电容（修正 case001 缺陷） |
| R1 | 10kΩ | 复位下拉电阻 |
| **R2** | **10kΩ** | 复位上拉电阻（修正 case001 缺陷） |
| SW1 | 常开按键 | 手动复位 |

**元件数**：9
**网络数**：5（VCC / GND / XTAL_OSC / RST / EA_GND）

## 3. 已知设计缺陷

### 缺陷 E1：晶振负载电容 C1 值不匹配（medium）

- **现象**：C1 = 10pF，C2 = 22pF；C1 偏离推荐值 22pF
- **后果**：负载电容偏小 → 晶振振荡回路增益不足 → 起振困难或频率偏移
- **规则命中**：CLOCK_001
- **对应 Ground Truth**：`DEF-CASE003-1`

## 4. 已验证的优良实践

1. **复位 RC 参数合理**：10kΩ + 10μF → τ=100ms
2. **复位拓扑正确**：R2 上拉 RST 到 VCC，提供高电平复位脉冲路径
3. **VCC 去耦电容正确**：C4=0.1μF 跨接 VCC-GND
4. **C2 值正确**：22pF 符合 Datasheet 推荐
5. **EA 硬件接地**

## 5. 观察项（非缺陷）

- 晶振电路**两侧电容不对称**（10pF vs 22pF）：本规则不检查对称性，只查绝对值是否在容差内
