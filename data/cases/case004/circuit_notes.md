# Case004 电路设计说明

> 案例元信息与设计背景，供规则引擎/RAG/评审参考

## 1. 案例来源

基于 8051 最小系统，外接 UART_BRIDGE（U2），制造两处 IO 冲突。

## 2. 电路组成

| 元件 | 型号/参数 | 作用 |
|---|---|---|
| U1 | STC89C55RC（DIP-40） | 8051 微控制器 |
| U2 | UART_BRIDGE | UART 桥接器件 |
| Y1 | 11.0592MHz 晶振 | 系统时钟源 |
| C1/C2 | 22pF | 晶振负载电容 |
| C3 | 10μF | 复位延时电容 |
| C4 | 0.1μF | VCC 去耦电容 |
| R1 | 10kΩ | 复位下拉电阻 |
| R2 | 10kΩ | 复位上拉电阻 |
| SW1 | 常开按键 | 手动复位 |

**元件数**：11
**网络数**：9

## 3. 已知设计缺陷

### 缺陷 E1：MCU 与外部器件输出直连（critical）

- **现象**：`CTRL_WR` 网络上同时有 `U1.P3_6`（MCU 输出）和 `U2.OUT`（外设输出）
- **后果**：推挽对推挽，可能大电流或损坏
- **规则命中**：IO_003
- **对应 Ground Truth**：`DEF-CASE004-1`

### 缺陷 E2：同 MCU 内部两个输出直连（critical）

- **现象**：`BUS_CONFLICT` 网络上同时有 `U1.P1_0` 和 `U1.P1_1`
- **后果**：推挽对推挽，可能内部短路
- **规则命中**：IO_002
- **对应 Ground Truth**：`DEF-CASE004-2`

## 4. 已验证的优良实践

1. **UART 互连方向正确**：TX→RX 交叉
2. **复位 RC 参数合理**：τ=100ms
3. **VCC 去耦电容正确**：0.1μF
4. **晶振负载电容对称**：22pF / 22pF

## 5. 观察项（非缺陷）

- IO_001：MCU 部分 IO 悬空（low 级提示，不计入 defect）
