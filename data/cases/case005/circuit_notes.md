# Case005 电路设计说明

> 案例元信息与设计背景，供规则引擎/RAG/评审参考

## 1. 案例来源

基于 8051 最小系统，外扩 32K×8 SRAM（62256）。

## 2. 电路组成

| 元件 | 型号/参数 | 作用 |
|---|---|---|
| U1 | STC89C55RC（DIP-40） | 8051 微控制器 |
| U2 | SRAM_62256（DIP-28） | 外部 32K×8 SRAM |
| Y1 | 11.0592MHz 晶振 | 系统时钟源 |
| C1/C2 | 22pF | 晶振负载电容 |
| C3 | 10μF | 复位延时电容 |
| C4 | 0.1μF | VCC 去耦电容 |
| R1 | 10kΩ | 复位下拉电阻 |
| R2 | 10kΩ | 复位上拉电阻 |
| SW1 | 常开按键 | 手动复位 |

**元件数**：11
**网络数**：16（含电源、地、晶振、复位、SRAM 控制/地址/数据）

## 3. 已知设计缺陷

### 缺陷 E1：SRAM 片选 CE 悬空（high）

- **现象**：U2（62256）的 CE 脚未连接到任何网络
- **后果**：CMOS 输入悬空 → 电平不确定 → SRAM 无法被稳定选中 → 读写失败
- **规则命中**：CTRL_001
- **对应 Ground Truth**：`DEF-CASE005-1`

## 4. 已验证的优良实践

1. **复位 RC 参数合理**：10kΩ + 10μF → τ=100ms
2. **复位拓扑正确**：R2 上拉 RST 到 VCC
3. **VCC 去耦电容正确**：C4=0.1μF
4. **SRAM OE/WE 正确连接**：OE→RD、WE→WR
5. **地址/数据总线部分连接**：A0-A4、D0-D3 已连接

## 5. 观察项（非缺陷）

1. **U2 的 A5-A14、D4-D7 未连接**：本 case 简化构造，非缺陷
2. **U1 部分 IO 悬空**：由 IO_001 汇总提示（low 级），不计入 defect
