# Case006 电路设计说明

> 案例元信息与设计背景，供规则引擎/RAG/评审参考

## 1. 案例来源

基于 case001（8051 最小系统）派生，做三处修改：
1. **删除 C2**：晶振只保留 C1（负载电容缺一个）→ CLOCK_002 命中
2. **C3 从 10μF 改为 1nF**：复位 RC 时间常数不足 → CTRL_002 命中
3. **新增 C4 + R2**：修正 case001 的 POWER_001 / POWER_002 缺陷

## 2. 电路组成

| 元件 | 型号/参数 | 作用 |
|---|---|---|
| U1 | STC89C55RC（DIP-40） | 8051 微控制器 |
| Y1 | 11.0592MHz 晶振 | 系统时钟源 |
| C1 | 22pF | 晶振负载电容（仅剩一个） |
| **（C2 已删除）** | — | 缺少对称负载电容 |
| **C3** | **1nF（误用）** | 复位延时电容（应 10μF） |
| C4 | 0.1μF | VCC 去耦电容 |
| R1 | 10kΩ | 复位下拉电阻 |
| R2 | 10kΩ | 复位上拉电阻 |
| SW1 | 常开按键 | 手动复位 |

**元件数**：8
**网络数**：5（VCC / GND / XTAL_OSC / RST / EA_GND）

## 3. 已知设计缺陷

### 缺陷 E1：晶振电路不完整（high）

- **现象**：XTAL_OSC 网络上只有 C1，缺少对称的 C2
- **后果**：晶振振荡回路不完整，可能起振困难或频率偏移
- **规则命中**：CLOCK_002
- **对应 Ground Truth**：`DEF-CASE006-1`

### 缺陷 E2：复位 RC 时间常数不足（high）

- **现象**：C3=1nF，τ = R1 × C3 = 10kΩ × 1nF = 10μs
- **后果**：远小于 8051 复位最小脉宽要求（2ms），无法可靠复位
- **规则命中**：CTRL_002
- **对应 Ground Truth**：`DEF-CASE006-2`

## 4. 已验证的优良实践

1. **C1 值正确**：22pF 符合 Datasheet 推荐
2. **VCC 去耦电容正确**：C4=0.1μF
3. **复位拓扑正确**：R2 上拉 RST 到 VCC
4. **EA 硬件接地**
