## 1. Buck 转换器热设计原则

### 1.1 器件功耗

线性稳压器（LDO）：P_loss = (Vin - Vout) × Iout
开关稳压器（Buck）：P_loss = P_out × (1/η - 1)
  - 其中 η 为效率，通常 75%~95%

### 1.2 结温估算

T_J = T_A + P_loss × θJA

- T_A：环境温度
- θJA：结到环境热阻（与封装、散热片、气流有关）
- T_J：结温

### 1.3 降额准则

- **必须**：T_J ≤ T_J_max × 降额系数（Ⅱ 级：≤ 95℃）
- **推荐**：留 20~30℃ 裕量
- **不推荐**：依赖散热片达到临界值（散热片失效则器件损坏）

## 2. 常见封装 θJA 参考

| 封装 | θJA（无散热片） | θJA（加散热片） |
|---|---|---|
| TO-220 | 65℃/W | 25~40℃/W |
| **TO-263（D2PAK）** | **50℃/W** | **25~40℃/W** |
| SOIC-8 | 120~150℃/W | 不适用 |

## 3. 降低功耗的方法

| 方法 | 效果 | 代价 |
|---|---|---|
| 改用同步整流 Buck | 效率从 80% → 90% | 成本↑，复杂度↑ |
| 降低 Vin | 减小压差 | 输入源受限 |
| 降低负载电流 | 直接减小 P_loss | 应用受限 |
| 加散热片 | 降低 θJA | 成本↑，体积↑ |
| 降低环境温度 | 降低 T_J | 场景受限 |

## 4. 本 Case 的应用

- LM2596：P_loss = 1.25W，θJA = 50℃/W，T_A = 85℃
- T_J = 147.5℃ > 125℃ → **超限**
- 解决方案：
  - ✅ 加散热片（θJA → 25℃/W，T_J → 116.25℃）
  - ✅ 改用同步整流（效率 90% → P_loss = 0.556W，T_J = 112.8℃）
  - ✅ 降低环境温度（工业级场景可能不允许）
  - ✅ 降低负载（< 0.5A，T_J < 116.25℃）
